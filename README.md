# DCS Mission Development Repository

This repository contains mission files, scripts, and resources for Digital Combat Simulator (DCS) mission development.

## Contents

This repository includes:

- **Mission Scripts**: Lua scripts for various DCS missions and scenarios
- **MOOSE Framework**: Mission Object Oriented Scripting Environment for DCS
- **CTLD & CSAR**: Troop transport and Combat Search and Rescue scripts
- **Audio Assets**: Mission audio files and sound effects
- **Map-Specific Missions**: Organized by DCS map (Caucasus, Syria, Marianas, etc.)

## Repository Structure

```
/DCS_Caucasus/       - Caucasus map missions
/DCS_Syria/          - Syria map missions
/DCS_Marianas/       - Marianas map missions
/DCS_Normandy/       - Normandy map missions
/DCS_Sinai/          - Sinai map missions
/DCS_Falklands/      - Falklands map missions
/DCS_Kola/           - Kola map missions
/DCS_Afgainistan/    - Afghanistan map missions
```

## Key Scripts

- `Moose.lua` - MOOSE framework for DCS mission scripting
- `CTLD.lua` - Combat Troop Lift and Deployment system
- `CSAR.lua` - Combat Search and Rescue system
- `mist.lua` - Mission Scripting Tools
- Various mission-specific Lua scripts
